# 方块地心 · 泰拉瑞亚风格 2D 沙盒

一款纯前端的 2D 沙盒生存游戏：程序化生成地形、挖掘与建造、昼夜循环、本地存档。
无第三方依赖，双击 `index.html` 即可游玩（也可用任意静态服务器托管）。

## 玩法

| 操作 | 说明 |
|------|------|
| `A` / `D` 或 `←` / `→` | 左右移动（支持自动上一格台阶） |
| `空格` / `W` / `↑` | 跳跃 |
| 鼠标左键 | 挖掘准星指向的方块（需在 5 格触及范围内） |
| 鼠标右键 | 放置当前选中的方块 |
| 数字键 `1`~`9` / 点击快捷栏 | 切换手持方块 |
| `F5` | 丢弃存档并重新生成世界 |

## 特性

- **无限随机的世界**：多倍频值噪声生成地表起伏，向下分布泥土、石头、洞穴，并按深度生成煤 / 铁 / 金三种矿石；地表自动生长树木、低洼处生成沙地。
- **瓦片物理**：AABB 与瓦片网格碰撞，重力 / 落速上限 / 空中操控 / 自动踩台阶，掉出世界底部会回到出生点。
- **挖掘与建造**：每种方块有独立硬度（决定挖掘节奏），挖掉即入背包；放置时禁止把实心方块塞进自己身体。
- **昼夜循环**：一昼夜 4 分钟，天空梯度、整体 multiply 压暗，火把提供局部暖光。
- **存档**：每 5 秒与关闭页面时把「与初始地形的差异」写入 `localStorage`，刷新后继续上一次的工程。
- **像素渲染**：Canvas 2D 逐瓦片绘制，带高光 / 阴影 / 矿石颗粒，镜头平滑跟随并限制在世界边界内。

## 目录结构

```
terraria-sandbox/
├─ index.html          # 页面骨架与 HUD 容器
└─ src/
   ├─ main.js          # 主循环：输入、物理、交互、HUD、存档调度
   ├─ world.js         # 世界生成（噪声地形 / 洞穴 / 矿脉 / 树木）与存档读写
   ├─ blocks.js        # 方块定义表（颜色、硬度、是否实心）与快捷栏配置
   ├─ renderer.js      # 渲染层：天空、瓦片、玩家、光照、选中框
   └─ style.css        # HUD / 快捷栏 / 背包样式
```

## 运行

直接打开 `index.html`，或在本目录起一个静态服务器：

```bash
python -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080
```

> ES Module 需要 http(s) 环境，若浏览器拦截 `file://` 下的模块加载，请使用上面的静态服务器方式。

## 扩展点

- 在 `blocks.js` 的 `BLOCK` / `BLOCK_META` 里追加方块即可扩充建造材料。
- 在 `world.js` 的 `oreVein` 之后追加生成器，可加入更多矿脉或结构（地牢、矿洞小屋）。
- `main.js` 中的 `handleInteraction` 是唯一的挖掘 / 放置入口，新增工具逻辑（如镐子等级限制）从这里接入。
